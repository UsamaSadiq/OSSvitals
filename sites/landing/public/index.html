OSS Vitals

How healthy is your open-source ecosystem?

Open, recomputable health dashboards for open-source project ecosystems, built from public data and refreshed every day.

How it works

  • Real data, collected dailyScores come from the project's own repository health checks, run every day by routine jobs. Nothing is estimated.
  • A published methodEvery check, weight and threshold is public, so anyone can recompute any score from the same data.
  • Nothing for salePayment never buys a ranking, a better score, or the removal of a public result.
